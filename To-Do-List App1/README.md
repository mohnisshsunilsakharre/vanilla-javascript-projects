# 📋 To-Do List App

A simple **To-Do List** app built using HTML, CSS, and JavaScript.
Its a plain JavaScript — also called Vanilla JS Framework.
It allows users to add tasks and delete them dynamically.

---

## 📂 Project Structure

TodoApp/
│── index.html # UI
│── style.css # Styling
│── script.js # Logic

---

## 🚀 How to Run

1. Open the project folder.
2. Double-click `index.html`.
3. Type a task in the input box.
4. Click **Add** → the task appears in the list.
5. Click **Delete** → the task is removed.

---

## 🛠️ Features

- Add tasks dynamically.
- Delete tasks individually.
- Input validation (no empty tasks).
- Clean and responsive UI.

---

## 📚 Concepts Learned

- Handling user input with JavaScript.
- Creating new HTML elements dynamically (`document.createElement`).
- Adding event listeners (`onclick`).
- Basic CSS styling with flexbox and box shadows.
