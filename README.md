# 🌐 My First Website Studies – Vanilla JavaScript Projects

## 🚀 Overview

This repository is a collection of beginner-friendly frontend practice projects created while learning **HTML, CSS, and Vanilla JavaScript** (plain JavaScript without frontend frameworks).

It includes small hands-on applications and website exercises that demonstrate core web development concepts, DOM manipulation, event handling, styling, and basic user interaction.

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JavaScript)
- Browser DOM APIs

## ✨ Projects Included

### 🔢 Calculator App
A basic calculator supporting arithmetic operations.

- Addition, subtraction, multiplication, and division
- Clear display
- Delete the last entered character

### 📋 To-Do List App
A simple task management application.

- Add tasks dynamically
- Delete individual tasks
- Basic empty-input validation
- DOM manipulation and event handling

### 🌍 My First Website
A starter website demonstrating basic HTML structure, styling, and JavaScript button interaction.

### 💼 Portfolio Website
A basic portfolio website exercise built with HTML and CSS.

## ▶️ How to Run

1. Clone or download this repository.
2. Open the folder for the project you want to try.
3. Open its `index.html` file in a modern web browser.
4. For easier development, open the repository in VS Code and use a local development server if desired.

No build tools or package installation are required for these basic projects.

## 📚 Concepts Practiced

- HTML page structure and semantic elements
- CSS styling and layout
- JavaScript variables, functions, and event handling
- DOM selection and manipulation
- Creating and updating elements dynamically
- Reading and validating user input
- Connecting HTML, CSS, and JavaScript files

## 🎯 Learning Goal

To strengthen frontend fundamentals through small practical projects before progressing to larger JavaScript applications and modern frontend tools.
