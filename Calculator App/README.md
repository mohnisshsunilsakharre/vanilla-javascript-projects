# 🔢 Simple Calculator App

A simple calculator built with **HTML, CSS, and JavaScript**.
Its a plain JavaScript — also called Vanilla JS Framework.
It supports basic arithmetic operations like addition, subtraction, multiplication, and division.

---

## 📂 Project Structure

CalculatorApp/
│── index.html # UI
│── style.css # Styling
│── script.js # Logic

---

## 🚀 How to Run

1. Open the project folder.
2. Double-click `index.html`.
3. The calculator will open in your browser.

---

## 🛠️ Features

- ➕ Addition
- ➖ Subtraction
- ✖ Multiplication
- ➗ Division
- 🧹 Clear display
- ⌫ Delete last character

---

## 📚 Concepts Learned

- HTML inputs and buttons.
- CSS grid layout for button arrangement.
- JavaScript functions:
  - `appendChar()` → add numbers/operators.
  - `clearDisplay()` → reset input.
  - `deleteChar()` → backspace.
  - `calculate()` → evaluate expression.
