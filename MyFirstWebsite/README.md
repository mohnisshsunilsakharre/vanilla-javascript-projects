# 🌍 My First Website

This is my very first website built with **HTML, CSS, and JavaScript**.
Its a plain JavaScript — also called Vanilla JS Framework.
It displays a heading, a welcome message, and a button that shows an alert when clicked.

---

## 📂 Project Structure
MyFirstWebsite/
│── index.html


---

## 🚀 How to Run
1. Open the project folder.
2. Double-click `index.html`.
3. It will open in your browser.
4. Click the button → a popup will appear.

---

## 🛠️ Concepts Learned
- Basic HTML structure (`<h1>`, `<p>`, `<button>`).
- Adding CSS styles (`background-color`, `text-align`).
- Adding JavaScript for button click events.
